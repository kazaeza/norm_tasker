# norm_tasker

Telegram-бот-помощник для SMM-команды проекта «VK Знакомства».

Бот ведёт трекер постов. Что и когда выходит, он берёт из контент-плана в Google Sheets, а кто какой пост взял и на каком тот этапе — из рабочего чата. По этому трекеру бот напоминает о сроках, делает утреннее саммари и следит за подготовкой КП на следующий месяц.

Статус: планирование. Подробный план — в [PLAN.md](PLAN.md).
