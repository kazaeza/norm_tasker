# norm_tasker

Telegram-бот-помощник для SMM-команды проекта «VK Знакомства». Бот следит за контент-планом в Google Sheets и делает утреннее саммари. Он напоминает о двух дедлайнах: пост готов за 2 рабочих дня до выхода и показан клиенту за 1 рабочий день. Ещё он собирает комментарии клиента и отвечает на вопросы о постах.

Статус: планирование. Подробный план — в [PLAN.md](PLAN.md).
