# norm_tasker

Telegram-бот-помощник для SMM-команды проекта «VK Знакомства».

Бот ведёт трекер постов. Что и когда выходит, он берёт из контент-плана в Google Sheets, а кто какой пост взял и на каком тот этапе — из рабочего чата. По этому трекеру бот напоминает о сроках, делает утреннее саммари, ведёт закреплённую доску и следит за подготовкой КП на следующий месяц. В КП он ничего не пишет.

**Статус:** этап 1 (без ИИ) готов к запуску — инструкция в [docs/SETUP.md](docs/SETUP.md). Общий план и договорённости — в [PLAN.md](PLAN.md). ИИ (свободные формулировки, вопросы боту) — этап 2.

## Как это выглядит в чате

```
Копирайтер:     беру пост на пятницу
Бот:            ✍️ Имя — пт 16.10 · №12 «Пост B». Текст клиенту — до ср 14.10 18:00.   [↩️ Отменить]
Копирайтер:     текст на пятницу готов, отправил клиенту
Бот:            👍
Ответственный:  по пятничному клиент ок по тексту, отдал дизайнеру
Бот:            👍 🎨 пт 16.10 · №12 «Пост B» — у дизайнера. Показать клиенту с дизайном — до чт 15.10 18:00.
```

Утром в 09:30 бот присылает одно сообщение: что горит, что должно быть готово сегодня, что уходит дизайнеру, как идёт КП на следующий месяц и какие новые комментарии оставил клиент. Если всё в порядке, напоминания молчат.

## Что понимает бот

| Сообщение | Что происходит |
|---|---|
| «беру пост на пятницу», «возьму №12», «беру» в ответ на сообщение бота | записывает автора |
| «@коллега возьми пост на среду» | просит коллегу подтвердить кнопкой |
| «не успеваю пост на среду» | пост снова свободен |
| «текст готов, отправил клиенту» · «клиент ок по тексту» · «отдал дизайнеру» · «дизайн готов» · «показал клиенту с дизайном» · «финальный ок» · «вышел» | двигает этап |
| «клиент вернул текст на правки» | откатывает этап назад |
| «пост №12 переносим на 20.10» | переносит и напоминает поправить КП |
| «кп окей» · «показали кп клиенту» · «беру кп» | этапы КП на следующий месяц |
| «не пост» в ответ на сообщение бота | убирает строку из трекера |

Если бот не уверен, о каком посте речь, он спрашивает кнопками. Каждое действие можно отменить кнопкой или командой `/undo`.

Команды: `/today` `/week` `/my` `/free` `/design` `/kp` `/post 16.10` `/add 15.10 тема` `/board` `/undo` `/inventory` `/status` `/id` `/help`.

## Сроки

Два срока задала команда, остальные бот рассчитывает между ними по производственному календарю РФ:

- **D−2** — текст готов и показан клиенту (копирайтеры);
- **D−1** — готовый пост с дизайном показан клиенту (ответственный за проект).

Дизайнера в чате нет, но график учтён: передавать ему лучше с 9 до 10 утра, крайний срок — 13:00 по Москве. КП на следующий месяц показывают клиенту 25-го числа (выходной — ближайший рабочий день), сборка стартует за 4 рабочих дня до показа. Подробности — в [PLAN.md](PLAN.md), все сроки настраиваются в `config.yaml`.

## Запуск

Подробно и с картинками мест, где искать настройки, — [docs/SETUP.md](docs/SETUP.md). Коротко:

```bash
cp .env.example .env               # токен бота и идентификаторы таблиц
mkdir -p data                      # сюда: config.yaml (из config.example.yaml) и service-account.json
docker compose run --rm bot python -m norm_tasker doctor   # проверка настроек
docker compose up -d --build
```

Полезные команды: `python -m norm_tasker doctor` — проверить токен, права бота и доступ к КП; `python -m norm_tasker parse выгрузка.xlsx` — посмотреть, как бот разбирает таблицу и какие сроки насчитывает.

## Разработка

Python 3.12.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
ruff check . && ruff format --check .
pytest
```

Тесты не ходят в сеть: Telegram подменён записью вызовов, Google — заготовками, КП строится генератором обезличенного xlsx (`tests/kp_fixture.py`). Настоящие данные клиента, токены и ключи в репозиторий не попадают.

## Устройство

```
src/norm_tasker/
  config.py, calendar_ru.py, deadlines.py   настройки, рабочие дни РФ, цепочка сроков
  kp/          разбор xlsx-выгрузки КП: недельные блоки, статусы, доки, комментарии
  tracker/     SQLite: посты, журнал и отмена, сверка с КП, команда
  chat/        распознавание сообщений без ИИ, выбор поста, ответы на кнопки
  digest/      что горит, саммари, напоминания, доска, КП на месяц, отчёт
  google/      Drive/Sheets: выгрузка КП, комментарии доков, копия трекера
  bot/         aiogram: обработчики, команды, циклы чтения КП и напоминаний
```
