# norm_tasker — памятка для Claude

Telegram-бот SMM-команды проекта «VK Знакомства»: трекер постов по контент-плану (КП) в Google Sheets, напоминания, утреннее саммари, доска, КП на месяц. Общий план — `PLAN.md`, запуск — `docs/SETUP.md`, устройство кода — `README.md`.

## Пользователь
- Владелец репозитория — копирайтер команды, не технарь. Отвечать по-русски, коротко и простыми словами, без жаргона; шаги — нумерованным списком.
- У облачной сессии нет браузера и доступа к его аккаунтам (Amvera, GitHub, BotFather). Клики делает он; токены, пароли и ключи он вводит сам. Токен бота в чат не просить, при утечке — `/revoke` в @BotFather.

## Ветки и выкладка
- Единственная ветка и ветка по умолчанию: `claude/smm-telegram-bot-plan-pcb17p`. `main` нет; PR и слияние — только по явной просьбе.
- Amvera следит за этой веткой: каждый пуш пересобирает и перезапускает бота на 2–5 минут (даже пуш одних документов), поэтому пуши лучше собирать в один.
- Перед пушем: `.venv/bin/python -m ruff check . && .venv/bin/python -m ruff format --check . && .venv/bin/python -m pytest -q`. CI (`.github/workflows/ci.yml`): тесты, ruff и сборка Docker-образа.
- Коммиты заканчиваются строками `Co-Authored-By: Claude <noreply@anthropic.com>` и `Claude-Session: <ссылка сессии>`; идентификатор модели в репозиторий не писать.

## Хостинг
- Amvera Cloud, проект `norm-tasker-2`, зона «Варшава», тариф Trial (100 МБ; бот занимает ~50 МБ), при нехватке — Starter. Образ из `Dockerfile` (база `python:3.12-slim-bookworm`), `amvera.yaml` задаёт `/data` как постоянную папку с базой.
- Переменные проекта: `BOT_TOKEN` (секрет), `KP_SPREADSHEET_ID`, `CONFIG_B64` (настройки команды, base64), `CHAT_ID` и `THREAD_ID` (после `/id` в чате), `GEMINI_API` (секрет; бот пока не читает). Настройки команды и сроков живут там, а не в репозитории; меняет их владелец в Amvera и перезапускает проект.
- Уроки: ничего не загружать в Amvera руками — история разойдётся с GitHub; если пуши не доходят, переподключить GitHub («Репозиторий» → «Удалить» → подключить заново); на `python:3.12-slim` зеркало Amvera падало.
- Доставка пушей в Amvera ненадёжна: после переподключения GitHub код подтянулся один раз, следующие пуши (CI зелёный) не дошли. Причина не установлена; по документации вебхук Amvera реагирует на один тип события (push или CI) и на остальные отвечает 400. Что смотреть: GitHub → Settings → Webhooks → вебхук Amvera → Recent Deliveries → Response.
- Какая сборка запущена, видно по первой строке `/status` («Версия …»). Хеш коммита в Amvera не совпадает с GitHub (там свой «Merge»), сверять по нему нельзя. Поэтому поднимайте `__version__` (`src/norm_tasker/__init__.py`) и `version` в `pyproject.toml` вместе с каждым изменением поведения бота.
- Баланс Amvera предоплатный: при нуле бот остановится.

## Приватность
Репозиторий публичный. Не коммитить токены, ключи, ссылки и идентификаторы таблиц, номера чатов, имена и username команды и клиента, выгрузки КП. Реальные данные — только в переменных Amvera.
